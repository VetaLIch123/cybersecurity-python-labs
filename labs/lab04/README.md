# Лабораторна робота №4

## Тема і мета

Інтеграція із зовнішніми Web API та автоматизоване тестування Python-коду. Утиліта отримує CVE з NVD CVE API 2.0, перевіряє структуру даних, аналізує CVSS v3.1 за правилом варіанта й друкує JSON-звіт. Локальний режим дає змогу запускати програму без мережі.

## Варіант 4

Навчальне правило: оцінка CVSS має бути не нижчою за `8.0`, а `userInteraction` — дорівнювати `NONE`. Результат `review` позначає лише відповідність цьому правилу. Він не є оцінкою ризику конкретної системи чи пріоритетом усунення.

## Встановлення

Команди виконуйте з кореня репозиторію у віртуальному середовищі Python 3.12 або новішому:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Для запитів NVD ключ не потрібен. Якщо є ключ, збережіть його у змінній середовища `NVD_API_KEY`; програма передає його тільки в заголовку `apiKey` і не друкує.

## Запуск

Локально, без мережевого запиту:

```powershell
python -m labs.lab04.main --cve CVE-2099-10001 --input labs/lab04/data/nvd_sample.json
```

Для варіанта 4 синтетичний запис має дати `review`, оцінку `9.8` та спостережене значення `NONE`.

Один ручний запит до NVD:

```powershell
python -m labs.lab04.main --cve CVE-2021-44228
```

Запускайте лише поодинокі ручні запити. Не використовуйте цикли або пакетне завантаження. Якщо API недоступний або обмежує запити, занотуйте це у звіті й покажіть локальний режим.

## Формат рішення

Звіт завжди містить `cve_id`, `variant`, `description`, `vuln_status`, `cvss_version`, `score`, `score_source`, `vector`, `rule`, `observed` і `decision`. Відсутні значення подаються як JSON `null`.

Стани: `not_found` — запису немає; `rejected` — NVD позначив його як відхилений; `insufficient_data` — потрібних даних недостатньо; `review` — оцінка не нижча за поріг і метрика відповідає правилу; `other` — дані достатні, але правило не виконане. Останні два стани не є висновком про безпечність чи реальний ризик.

## Тести та стиль

Тести ізолюють HTTP і забороняють випадкові мережеві запити:

```powershell
python -m pytest labs/lab04/tests -q
ruff check labs/lab04
ruff format --check labs/lab04
```

Тест межі перевіряє значення нижче `8.0`, рівно `8.0` і вище `8.0`. Порівняння включає рівність: у коді використано `score >= threshold`.
